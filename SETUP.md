# Подготовка окружения

## Инструменты
- Minikube, kubectl, Python 3, pip, Locust
- draw.io + библиотека иконок Yandex Cloud (локально в `drawio-libs/`)

## Как подключить иконки Yandex Cloud в draw.io
1. Откройте [app.diagrams.net](https://app.diagrams.net) или desktop draw.io
2. File → Open Library from → Device / URL
3. Укажите файл `drawio-libs/Yandex_Cloud_services_oct_23.xml`
   или URL: https://code.s3.yandex.net/software-architect/Yandex_Cloud_services_oct_23.xml?etag=2b1ed124cee4731d14f2691b9a187e45

Решения заданий — в директориях `Task1` … `Task6`.
